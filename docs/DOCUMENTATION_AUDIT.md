## Scope and method

The former mixed-date context was archived before replacing the current handoff. Historical score tables, decisions and dated results were retained rather than rewritten as current measurements.

The repository has **no database, schema/migrations, authentication/accounts, durable review sessions or frontend package/build manifest** to document. Its core is Python standard library plus vanilla browser code. `requirements-tracing.txt` is the optional Sentry dependency; the installed `.venv` is generated local material. The absence of a persistence layer is an implemented limitation, not a pending database setup step.

Actual `.env` contents were neither opened nor sourced. Only safe variable names and the tracked example were inspected. No dependencies were installed, no fresh inference/model download was performed, and no account, billing, deployment, commit, push or publication action was taken.

## Principal factual corrections

- **Inputs and storage:** users can paste dated text/WhatsApp text exports or upload text, without first making a CSV. There is no WhatsApp connection, ZIP/media import or automatic ingestion. Review work is browser memory, not a saved session; shipped fixtures/caches and temporary tracing run metadata are separate. No reload recovery was invented.
- **Model and code:** the model copies phrases and proposes status/replacement hints. Code resolves people/dates/times and reconciles/counts; a person reviews. API overrides are trusted local-client inputs with incomplete validation, not an authentication or general schema-validation boundary.
- **Review/export:** accepted-only records are replayed for final CSV. Completeness requires explicit review of all non-duplicate messages, no pending claims and no blocking issue. Provisional downloads remain possible; accepted conditions alone do not block completeness. Message marks affect status/cell review states, not permission to download.
- **Replay/privacy:** hosted set-A saved-output checks do not identify every possible private value in arbitrary claim/override payloads. Tracing is opt-in with application-side allowlists. Received geo attributes and targeted filtering were observed; their origin and a complete received-payload audit remain unverified.
- **Evidence:** frozen first scores, later post-hoc fixes, all-pending provisional-ledger metrics, reviewed-CSV accuracy and unperformed human timing are separate. A/B share an assistant author; C was isolated ChatGPT work with five owner-rewritten messages. No independent real-user accuracy/time-saving study is claimed.
- **Status/history:** current Actions/Render/release verification, implemented COR-13–18, completed set-C scoring and dropped ElevenLabs supersede older work orders. Historical prompts, old counts, original goals and evidence remain explicitly dated. The latest observed CI run is #18 on `d4b2f76`, not #17 on `a4bebb7`.
- **Operating instructions:** core requires no pip dependencies; Sentry SDK is optional. Cache-only model/hybrid checks use temporary outputs and refuse a cache miss; evaluation is otherwise capable of fresh inference on a miss. No actual secret values were included.
